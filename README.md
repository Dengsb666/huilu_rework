# 回炉重造扩展包

这是一个用于收录“保持原版规则、修复实际实现问题”的 FreeKill 自定义武将包。

## 当前武将

- 回鲁肃（`huilu__lusu`）：3 体力，吴势力。
- 好施（`huilu__haoshi`）：与神话再临·林的鲁肃实现一致。
- 缔盟（`huilu__dimeng`）：与神话再临·林的鲁肃实现一致，并修复选择两名目标之前装备区不展开、导致无法用装备牌支付弃牌差值的问题。
- 回OL刘辟（`huilu__ol__liupi`）：保留原版〖易城〗，修复未选择整体交换时仍拿走全部展示牌的问题；只有实际完成首段等量交换且展示牌点数和因此增加，才可选择整体交换。
- 回手杀杨仪（`huilu__mobile__yangyi`）：完整拥有〖度断〗和〖共损〗；两项技能均收录在本包内，不依赖未安装的海外包。
- 回OL曹婴（`huilu__ol__caoying`）：保留〖凌人〗和〖伏间〗，删除凌人猜对两项时“此牌不计入次数”的收益，仍摸两张牌。
- 回势桓阶（`huilu__m_shi__huanjie`）：〖共谋〗只能选择手牌数不大于自己的其他角色；其余效果及〖正朔〗不变。
- 回手杀神姜维（`huilu__mobile__godjiangwei`）：调整为3体力、3体力上限；〖天涛〗改为非锁定技且只处理手牌区；〖星魂〗的展示阶段可取消，展示后至多使用一张【杀】，该【杀】结算后目标可重排牌堆顶五张牌但不能置于牌堆底；〖神霈〗的回复量仍为进入濒死次数，但雷电伤害固定为1点；〖回天〗不变。

## 兼容性约定

- 包 ID：`huilu_rework`
- “回”武将使用 `huilu__<原武将ID>`；例如“回鲁肃”为 `huilu__lusu`。
- 带版本前缀的武将使用 `huilu__<版本>__<原ID>`，例如 `huilu__ol__liupi`；最后一段仍是原武将 ID，保证引擎真名识别正确。
- 技能使用 `huilu__` 前缀，避免覆盖其他扩展包中的同名实现。

## 安装

将仓库克隆到 FreeKill 的 `packages/huilu_rework`，随后在包管理器中启用“回炉重造扩展包”。联机服务器也必须安装并启用同一 Git commit。
